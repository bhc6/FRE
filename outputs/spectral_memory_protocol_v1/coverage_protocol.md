# 动作时间证据覆盖：预声明协议

declared_at_utc: **2026-11-01T09:49:42Z**

本协议在本次覆盖评分运行前声明。制定者未访问确认集 QA 结果；此时间戳不声称此前没有任何其他实验产物。动作标注只进入独立覆盖评分器，不进入隐藏态提取、记忆选择、参数选择或读出提示。该评估测量采样证据的时间覆盖，不等于动作已被看清、识别、理解或成功用于 QA。

## 样本、事件和预算

- 视频集合固定为 `data/perception_confirm/videos.jsonl` 的 40 个新视频，排除开发集不由动作结果决定。
- 采用官方 train/valid temporal action localisation 标注，全部动作实例纳入，不按动作类别、QA 正误或方法表现挑选。
- 短动作固定定义为官方持续时间 `end_s - start_s <= 2.0` 秒；阈值不随观察结果改变。
- 报告全部动作与短动作两个预定分层。每层分别列出 64 帧观察中零命中的动作和至少命中一帧的动作。
- 全部方法按相同 2/4/8 pairs 预算评估，主要预算为 4 pairs（8 帧）。pair 表示输入采样序列中相邻两帧的位置，不是视频解码帧号。
- `full_reference`、`last_pair_reference` 是不同实际预算的诊断，单列实际保留帧对数；不进入同预算主比较。

## 唯一主要覆盖指标

主要指标是：**可观察短动作中，保留至少一个实际源帧的比例，先在每个视频内部求均值，再跨存在可观察短动作的视频求宏平均**。

动作区间采用闭区间 `[start_s,end_s]`。观察或保留的某帧只有在其 `source_frame_timestamps_s` 落入该区间时才计为命中。不能用目标采样网格时间、pair 中点或插值时间代替源帧时间；重复解码源帧只能计一次。

令 `O_e` 为完整观察中落入动作 `e` 的不同源帧集合，`M_e` 为持久化记忆保留的集合。可观察指 `|O_e| >= 1`，命中指 `|M_e| >= 1`。`O_e` 为空的动作不进入条件保留率分母，但必须单独报告数量、比例、视频分布，并计入全部动作的无条件覆盖率。

主要方法对比为 `spectral_balanced - temporal_centered` 和 `spectral_balanced - kcenter`，主要预算 4 pairs；同时完整展示全部方法及预算，不仅报告有利比较。两个主要对比共享主要指标，置信区间不作多重比较校正，因此不据此声明经家族错误率控制的显著性。

## 次要指标

1. 所有可观察动作的同定义视频宏平均 hit rate。
2. 短动作及全部动作中，保留至少两个不同源帧的比例；条件分母分别是完整观察本已有至少两个不同源帧的动作。
3. 可观察动作的至少一个原连续采样 pair 被完整保留的比例；条件分母是完整观察存在两个不同源帧均在动作区间内的原 pair 的动作。这比“两帧任意命中”更严格，仍不证明连续原视频动作被充分见证。
4. 动作微平均 hit rate、因记忆压缩变为零命中的数量/比例、各视频及各动作实例明细、全部动作无条件覆盖率。
5. 64 帧观察自身的零命中率及至少两帧/至少一个完整 pair 可观察率；这些是上游观察不足，不归咎于选择器。

每个动作实例等权；长动作和短动作分别按预定分层报告。重叠动作保留为独立官方实例，不按类别合并。缺失某视频的官方动作标注需明确报错，不能静默从分母删除。官方零动作视频保留在视频计数中，但事件均值无分母的视频不以零填充；报告各指标实际视频分母。

## 配对统计和限制

- 以原视频为配对重采样单元，10,000 次 bootstrap，随机种子 17，95% percentile 区间。
- 每个对比使用相同动作集合与相同视频分母；先求每个视频的方法差，再重采样这些视频差。视频只有一个时仍报告数值并标记推断不足。
- 参与者身份未知，视频 bootstrap 不保证跨参与者独立性。不同预算、次要指标和其余方法比较均属描述性补充。
- 必须保存源 URL、下载归档 SHA-256、内部 JSON SHA-256、每个动作的原始字段到标准秒单位的映射、输入清单 SHA-256、评分器源码 SHA-256。
- 评分器只读取帧时间/索引、动作区间和记忆索引，不读取 QA 问题、答案或回答结果。选择器看不到动作区间。
- 该结果不能代替 QA 收益；即使短动作覆盖改善，也需要独立验证实际任务表现。
