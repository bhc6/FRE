# 分频带记忆选择：独立确认协议 v1

本协议在新 40 视频的 QA 推理结果可见前冻结。开发仅使用原 8 视频/36 QA，包含已经看到的负结果；另有一个视频的固定尾部诊断。这里定义的是有限事件观察结束后的外部视觉记忆，不是持续无限流的在线算法。

## 问题与假设

已观察到两类失败：固定帧预算的全片均匀采样会漏掉短暂动作的已观察证据；小模型也可能在末帧本身可读的情况下被多帧上下文影响。固定尾部对照未证实“重复早期状态造成干扰”，所以后一机制不是本轮既定前提。

候选方法 `spectral_balanced` 对完整已观察轨迹做分频带相对重建保真约束，贪心选择真实相邻帧对，并按时间顺序存储。三个相对频带为 `(0,1/8]`、`(1/8,1/4]`、`(1/4,1/2]` cycles/hidden sample；每带分母是自身动态能量加 `0.01 × 总动态能量`，保留复系数相位。它没有新增输入信息，等价于依赖输入轨迹的时域加权二次损失。

可否证假设是：这个目标比同预算强对照保留更多短暂时间证据，并改善实际存储记忆的时序/状态问答。频谱重建误差降低本身不是任务成功。

## 数据冻结

确认集为官方 Perception Test validation 中固定选出的 40 视频、182 QA，含 32 个官方 memory 问题。按视频是否包含 memory 问题分两层，各从 `SHA256("spectral-confirmation-20261101:" + video_id)` 升序取 20。排除原 8 视频、需要官方 cut 的视频及 cup-game 视频；不看答案值或模型结果。

选择表 SHA-256：`1b8fecc04a8b15cd78c2cf0f4ce6d4006d71e4340951d4b862294d840156977a`。QA 文件 SHA-256：`40d2a6d5813c46ab25f0e283b1f3741666022bd3c617dff2614768245e9c6586`。全部正文、选项和真值已对照官方原始 JSON，视频 CRC/SHA 已核验；8 个开发视频与确认集 ID/视频文件哈希均无交集。

这是带 memory 富集的分层子集，不代表完整 benchmark 分布。参与者身份未知；视频级隔离和 bootstrap 不能证明跨人泛化。数据集可能存在相似场景，模型预训练污染也未排除。

## 方法、资源与主要比较

- 主观察表示：冻结 Qwen3-VL-2B revision `89644892e4d85e24eaac8bacfd4f463576704203` 的层 0，64 输入帧合成 32 个时间格。层 14/28仅作为已保存的后续分析资源，本轮不按确认结果挑层。
- 固定预算：2/4/8 个帧对，即 4/8/16 帧；主预算为 4 对。全部存储帧统一成保持比例的 512×288 RGB 画布，黑边补齐，无裁切。每个自包含 NPZ 的真实字节数依次为 1,770,300 / 3,539,820 / 7,078,860。
- NPZ 保存 uint8 帧、float64 时间戳和 int32 帧索引；QA reader 只读该文件、问题和选项，不读取原视频或完整隐状态。审计日志不作为模型输入；实际部署仍需另计文件目录/索引元数据，不能将此称为整个进程总存储。
- 对照：uniform、recent、random(seed17)、temporal_difference、kcenter、temporal_reconstruction、temporal_centered、spectral_power；另有全部 64 帧参考和无视频参考。除 recent 外，各选择器强制保留首尾帧对，因此预算 2 时其结果退化为相同，这一预算不用于证明频谱贡献。
- temporal_centered 使用去均值的时域重建残差，使其与频谱目标共享 DC 处理；temporal_reconstruction 保留原始时域均方误差。spectral_power 丢弃原通道复系数的相位。频带权重、DC、相位必须分别解释。
- 主 reader：同一个 2B 模型，BF16、SDPA、batch1、每帧最大 65,536 像素。所有题用首个输出位置上合法 A/B/C 等单 Token 的 logit argmax，排除自由生成格式失败；此评分与旧 144 次自由生成分开报告。

主要 QA 子集 `temporal_state`：官方 tags 包含 `change detection` 或 `sequencing`，或问题文本匹配大小写无关完整词 `before|after|first|last|beginning|end|order|changed|change|remember`。不使用正确答案定义子集。主分数为子集内原视频宏平均正确率。

主对照为主预算上的 **spectral_balanced − kcenter**。kcenter 在原开发集预算 4 的总体正确数最高（26/36），不是按确认集结果选择。机制对照为 spectral_balanced − temporal_centered，同时报告原时域重建与 magnitude 消融。全部问题、官方 memory 子集、其他预算都是次要结果。

预声明继续门槛：主对照至少提高 3 个百分点且原视频配对 bootstrap 95% 区间下界大于 0；机制对照也要求正增益且区间下界大于 0，方可支持频带均衡的独立任务价值。10,000 次 bootstrap、seed17，不将一个视频的多个题视作独立样本。其他比较区间不做多重检验校正，只作描述性分析；不凭其中偶然显著的一项宣布成功。

## 独立机制指标与迁移

官方动作区间仅用于评分。预先定义短动作 ≤2.0 秒；覆盖诊断按实际解码源 PTS 计算，在全部动作与 64 帧观察中可见的动作分别报告。主要覆盖指标是可观察短动作至少保留一个源帧的视频宏平均命中率；连续两帧见证及全部动作是次要项。观察源中本来没有任何帧的事件不可由选择器恢复，必须单列。

动作证据覆盖改善不自动等于 QA 改善；覆盖标注不能参与选择器、参数、层或阈值选择。完整覆盖实现与来源另外存档。

第二 reader 拟采用独立家族的公开 SmolVLM2-500M-Video-Instruct；它只读取相同冻结帧记忆，测试 reader 迁移而非观察表征迁移。其官方视觉分辨率/token 接口不同，所以不将跨模型延迟差归因于参数量；若接口或能力不足，应报告失败，不偷偷更换数据或评分。

## 执行与解释规则

保存输入、选择源码、reader、prompt、模型 revision 的哈希和运行源码快照。中断后只在配置及源码相同的情况下续跑；原始记录不覆盖。缓存只复用同问题、同内容记忆、同配置的真实前向。

选择器、64帧提取、图像写入和查询读出开销分别核算。均匀/近期/随机策略本来不需要隐状态提取，不能给它们强加该成本来制造效率优势。现阶段逐事件观察工作区有 64 帧和全轨迹，与持久化小记忆不同；未实现跨事件有界更新。

若频谱方法未达到上述证据要求，保留完整负结果，不能把重建指标改善、后验成功个案或扩大样本后偶然获胜替代主结论。修订方法须使用新的开发/确认分隔；本 40 视频一旦查看结果，不再是后续修订的独立确认集。
