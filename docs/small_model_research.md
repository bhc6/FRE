# 小模型研究定位：有限预算下的视觉时序记忆

核查日期：2026-11-01；同日补查近期直接竞争、机制区分及可执行的继续/停止门槛。

## 结论：可以以小模型为主要研究对象，但贡献必须超过模型尺寸

小模型不妨碍顶会研究。正式会议已经接收针对小型 VLM、移动端 VLM 和高效视觉语言架构的研究，见下一节的一手论文集证据。它们证明研究对象和资源约束可以成立，不证明本项目必然被接收，也不能用模型参数量推算录用概率。

本项目更合理的主线是：**在固定存储和计算预算下，小 VLM 丢失哪些视觉状态变化与事件关系，外部记忆如何保留这些动态证据，并改善未来问题的恢复能力？** 频谱是候选表示与压缩工具，小模型是明确的资源条件。两者都不是预先成立的贡献。

当前可用的 Qwen3-VL-2B 适合作为主试点：复用已有权重，冻结骨干，先验证观察、时间对齐和问答读出。使用一个已有 2B backbone 本身不能称为新模型；缓存存在也不等于专用提取适配器、时间对齐或真实收益实验已经验证。

## 将问题收敛成三个可否证假设

设视频流截至时点 `t` 的历史为 `X≤t`，冻结小模型为 `F`，在线记忆为 `M_t`，持久化预算为 `B`，观察与问答计算预算为 `C`。在未来查询分布上评估实际 reader 输出，不把候选记忆的预测分数当任务分数。

**H1：记忆丢失的是可定位的动态关系。** 固定骨干后，压缩或长时间干扰使顺序、方向、状态更新、最后出现位置等任务下降，且下降不能完全由单帧检测/识字失败解释。若提供完整可见证据也不能回答，就先解决读出或感知限制，不把其失败归因于记忆压缩。

**H2：有选择地保留动态比简单保留更多内容更有效。** 在相同 `B,C` 下，提出的选择/压缩方法优于均匀采样、近期优先、语义检索、时域差分/自相关、局部分段摘要及至少一个适用的强记忆压缩方法。若收益仅来自更多视频帧、更多重编码或更长 prompt，假设没有被支持。

**H3：频谱提供有用的归纳偏置。** 在输入、训练数据、调参次数、容量和时间定位能力匹配后，频谱分支改善跨视频/跨主体动态恢复。若给予时域对照同等局部顺序和时间定位能力后增益消失，不继续坚持 FFT 是核心创新。相位消融导致性能下降可以支持“方向信息重要”，但单独不能证明频域表示不可替代。

完整 Fourier 变换是原序列的可逆表示，不创造原始时域序列中没有的信息。功率谱不能区分任意序列与其反转。H3 检验的是有限容量和预算下的表示效益；数学与干预细节见 [研究审计](research_audit.md)。

写入与查询必须分离：query-free writer 只能看当前及过去观察；未来 query、答案、oracle 证据区间不能提前进入写入。query-conditioned retrieval 可以使用查询，但应独立报告。标准冻结因果 decoder 的旧 token 不因追加后缀而改写；长期干扰实验应作用于真正更新/压缩的记忆或未来检索与读出。

### 小模型机制：把四种失败拆开

“2B 比更大模型准确率低”不能解释记忆机制。建议用同一个冻结 reader 做以下干预；标注证据只用于诊断参考，不允许进入部署时的 writer。

| 失败来源 | 最小可执行的诊断 | 可得结论与限制 |
| --- | --- | --- |
| 感知/局部读出失败 | 直接提供人工标注的相关局部片段，且不提供答案；检查对象、文字、动作与状态是否可读 | 如果这样仍失败，外部记忆选择未必能弥补；这个条件是证据参考，不是保证最优的 oracle |
| 检索/控制失败 | 固定同一记忆库及同一 token 预算，比较自行检索与直接供给正确证据的 reader | 能定位“已有证据但取不到”；需与 OASIS、Harness Compilation 的相关思想区分 |
| 表示/压缩失败 | 固定已选中的同一事件，只替换其表示或压缩方式，再让 reader 解答顺序/状态问题 | 才能识别表示是否丢失动态；不能把更好的事件选择误归因于频谱压缩 |
| 干扰/整合失败 | 保持目标证据不变，用等 token 数、等预算的干扰证据替换其他上下文；分别匹配语义与动态相似度 | 若正确证据仍在却回答下降，才有读出干扰证据；不会因此证明旧因果 hidden state 被改写 |

每个条件同时报告静态识别和动态关系指标。若方法仅改善识字/物体识别，贡献应如实命名，不能称作时序记忆机制。

若进一步主张“对小模型尤其有用”，需测试尺度与方法的交互：`G_small = A_small(method) - A_small(baseline)`，`G_large` 同理，检查 `G_small - G_large` 的配对组级置信区间。小模型自身增益为正，不等于该交互为正；相同家族不同规模也可能有训练差异，因此这里只声称经验上的尺度交互，不声称已隔离参数量的纯因果效应。缺少尺度对照时，标题应写“小模型条件下的有效记忆”，不写“小模型特有机制”。

## 模型与计算设计

1. **主试点：Qwen3-VL-2B。** 使用本地已核实 revision 和专用时间对齐适配器；固定 prompt、采样策略、精度、视觉分辨率与预声明层。其名称中的 2B 是模型标签；记录实际模型配置，不能将不同模型的语言部分/总参数量混在同一尺度图里。
2. **第二个小模型：独立家族或不同视觉连接方式。** 用于检验方法是否只适用于一个 backbone 的表征。模型选择依据可获得权重、视频/多帧接口和可核算开销，不必以“最新”作为标准；先完成主试点再实施适配。
3. **同家族尺度对照：小范围即可有价值。** 在资源允许时加入同家族更大一档，区分“算法普遍改善”与“更明显地弥补小模型瓶颈”。跨家族 2B/3B 不是纯参数规模因果对照，因为训练数据和结构也变了。
4. **量化与 offload 单列条件。** 若 2B 用 BF16、较大模型用量化或 CPU offload，不可直接将延迟差解释成参数尺度效应。可以在一致量化设置下比较，或将这些设置作为独立系统配置。
5. **无需从头训练大 VLM。** 第一版冻结 backbone，只实现可审计的事件表示、轻量预测/选择与固定 reader。训练更大模型不是当前科学问题的必要前置；正式结论仍需要足够数据、模型对照与机制验证。

本项目当前提取接口是否已支持 Qwen3-VL、是否成功跑通应以代码与运行报告为准；本文不将“有权重”写成“已获得实验结果”。

## 预算必须能支撑公平的 Pareto 比较

至少报告三条可复核的轴：未来任务分数、持久化记忆字节、端到端计算/延迟。Pareto 改善指在某一资源范围内，同等任务表现需要更少资源，或在同等资源下表现更好；单一随意挑选的预算点不足以概括整条曲线。

存储需计入记忆向量/图像或片段、时间戳、索引、文本、检索键值和任何可重新读取的原视频。观察端计入视频解码、骨干前向、特征提取和写入；查询端计入检索、重新编码、prefill 与 generation。峰值 GPU 显存、持久化存储与参数量是不同量，不能互相替代。

建议使用预先固定的多个预算点和多个真实时间间隔，所有方法在同一 GPU、相同批量、输入分辨率、采样和解码上限下计时，分别报告冷启动与稳态。冻结骨干的可复用特征缓存应所有候选方法共享；若从纯算法开销中剔除观察成本，也要另报包含该成本的完整系统结果。

full-memory 是读出参考，不是同预算竞争者。方法若只优于 no-memory，说明证据有用；方法若只接近一个输入更长的 baseline，也没有证明其选择机制更优。

## 首轮协议：先用真实 QA 检查证据通路

范围限定为当前 Perception Test 官方 sample 的 **8 视频、36 个 MCQA**，其中仅 **1 题**原始标签为 `area=memory`。这些视频集中于相近场景；它们可以用于工程验证和案例分析，不足以支撑长期、多主体、泛化或顶会竞争力结论。EPIC 的 10 秒第一视角样本同样只用于对齐检查。

该 8 视频样本一旦被用于调试或查看结果，应永久标为开发集；不能后续称为独立验证集。仅 1 道官方 memory 题的准确率只能是 0% 或 100%，不能代表记忆能力分布。没有可靠参与者元数据时，8 条视频也不能声称是 8 位独立用户。下节数值门槛用于**尚未用于开发的新数据**，不能回填到已经看过的结果上，或将本文发布日期冒充过去的预注册时间。

| 条件 | 读出可见内容 | 目的与解释限制 |
| --- | --- | --- |
| `no_memory` | 同一个问题与选项，不提供视频证据；不给答案或 gold 相关元数据 | 检查语言先验/选项捷径，不是实际长期记忆系统 |
| `partial_memory` | 按事前固定策略/预算选出的部分帧或事件；query-free 版本选择时不看问题 | 检查有限证据如何影响读出；首轮固定均匀或近期策略，不在 8 视频上训练新选择器 |
| `full_memory` | 固定采样方案下的完整可见视频序列，使用相同 reader/prompt/解码规则 | 检查现有 reader 能否利用完整观察；它不是全像素 oracle，也不是同存储预算基线 |

三组保持 question/options、模型 revision、答案解析、解码参数和随机种子一致。因可见证据不同，输入 token 数允许不同但必须记录。不要为制造统一长度而使用带有任务信息的 padding，也不要让 gold answer 决定 partial 的位置。

预先记录：每题预测、原始 gold、正确性、读出时间、输入 token、实际视频/帧时间及显存。按原视频保留所有题，报告每个视频的结果和总体描述统计；不把 36 个相关问题视为 36 个独立主体样本。只对预先指定的字母顺序/变化题做案例分析，不把事后挑选的成功案例包装成新 memory benchmark。

首轮检查规则：

- 若 `full_memory` 不能稳定回答关键动态题，先排查视频采样、视觉 token 对齐、识字与答案解析；不直接训练效用预测器掩盖问题。
- 若 `no_memory` 与 `full_memory` 接近，检查问题是否主要依赖常识/语言先验、视觉证据是否真的进入模型。接近可能由样本太少造成，不能直接否定记忆研究。
- 若 `full_memory` 相对 `partial_memory` 改善，只说明丢失证据可能造成问题；尚未支持频谱方法。
- 这些结果只能决定下一阶段是否值得扩数据，不能决定论文已经达到投稿质量，也不能由单个 memory 题计算有说服力的泛化结论。

## 正式研究所需的证据与停止条件

| 有投稿研究价值的结果形态 | 目前不能支持的主张 |
| --- | --- |
| 多主体真实第一视角与真实长视频任务中，在多个预算/时间间隔下稳定改善状态、顺序和事件关系恢复 | 8 视频高准确率就代表 lifelong memory |
| 同观察成本、同存储、同 reader 和同查询可见性的强语义/时域/压缩对照，以及固定预算集合的实际 QA 评估 | 使用2B所以天然高效；候选分数提高所以答案提高 |
| 反转、相位、等能量频段扰动、动态相似但语义不同干扰，以及真实自然干扰共同支持具体机制 | 全局功率谱可视化证明动作方向或记忆价值 |
| 至少第二模型的迁移证据；若主张小模型特有瓶颈，需有同家族尺度或相当严谨的容量对照 | 在一个模型上有效就说明对所有小模型成立 |
| 基于主体/原视频的配对统计、训练/验证/测试隔离、独立确认集和完整成本报告 | 将同视频多个窗口/问题当独立样本得到很小 p 值 |

正式阶段应事前确定最小有用增益与成本约束，依据真实 pilot 方差规划有效主体/视频量；不在看完测试结果后设阈值。若频谱在强时域及等容量控制后没有稳定增益，则转向一般的时序结构保持；若连完整证据的读出都长期受感知能力限制，则应收窄任务或改善证据接口，不继续将失败解释为长期遗忘。

### 可直接执行的继续/停止门槛

以下数值是**本项目建议采用的投入决策门槛**，不是领域公认标准、统计功效保证或会议录用标准。应在新数据结果可见前将数据 manifest、代码/模型 revision、主指标、预算、随机种子和阈值写入不可混淆的协议版本；发现接口不适用时可以在开发阶段修订，但随后必须用新的确认数据。

主指标预设为动态关系 QA 的主体宏平均准确率；没有主体标签的资源则用原视频宏平均，并明确不声称跨用户泛化。答案解析失败算错且单列；所有方法使用同一测试问题。95% 区间对最高层独立分组做配对 cluster bootstrap，不对同视频窗口单独抽样。

| 阶段 | 继续标准 | 未达到时的动作 |
| --- | --- | --- |
| **G0：工程有效性**，当前 8 视频开发集 | `no_memory/first_half/last_half/uniform_full` 四组各 36 个结果记录齐全（共 144 次生成、108 条相对空记忆的效用）；原始 video/question ID、答案、时间戳及模型配置可追溯；无 gold 输入泄漏；无静默丢帧/跳题；所有有效采样时间严格递增；预算无超限 | 修复提取/解码/读出接口后重跑受影响项。QA 高低不作为该阶段的论文 go/no-go |
| **G1：是否有可利用的动态证据**，另取至少 20 个原视频、100 道动态关系题作为新的 discovery set | 直接供给相关证据的 reader 准确率至少 60%，相对 no-memory 至少高 10 个百分点；在预设的主要受限预算下，相关证据参考又比最强简单预算基线高至少 5 个百分点 | 不进入复杂记忆学习。先诊断感知/采样/问题捷径，或确认任务几乎没有可改善空间；这些 discovery 数据之后不得用于独立确认 |
| **G2：记忆方法值得扩展**，独立确认集 | 相对预先指定的最强适用基线，在主预算下主体/视频宏平均提高至少 **3 个百分点**，配对 95% 区间下界大于 0；另两预算点增益方向均非负；所有方法遵守同一存储与计算上限 | 区间跨 0 为“证据不足”，若预先规划的样本量已完成则暂停扩投入；点估计不足 3pp 即便显著，也未达到本项目有用改善门槛 |
| **G3：频谱值得留作主要贡献**，沿用未调参的确认集与固定主预算 | 在已包含语义、强时域、多尺度/局部顺序、等维度和等容量对照的完整方法上，频谱增量至少 **1 个百分点**且配对 95% 区间下界大于 0；频谱计算也计入同一上限 | 若整体记忆方法有效而该项失败，删除“频谱是主要创新”的主张，保留一般的动态结构保持研究；不靠换层、换频带、挑题恢复显著性 |
| **G4：可迁移性与机制边界** | 第二个小模型在预声明主预算下重复得到正向增益；如声称模型无关，要求其配对 95% 区间下界也大于 0；如声称小模型特有，则尺度交互 `G_small-G_large` 的区间下界须大于 0 | 仅第二模型方向为正但区间跨 0时，称为初步迁移迹象；尺度交互失败就收窄为特定小模型设置，不能保留“特有机制”论断 |

确认集建议的最低组织规模为 **12 个未用于开发的主体、36 条原视频、200 道动态关系 QA**；这是有效分组的组织下限，不保证能识别 1–3pp 的小效应。按 discovery 的组间方差预估需要的独立主体/视频数，再锁定确认样本量；若所需规模超出资源或置信区间过宽，结果应标为不确定，不能用增加同一视频的近重复题来代替独立样本。公开数据不能提供 12 个独立主体时，应明确更换为跨原视频研究目标或补充获准数据，不能猜测主体 ID。

预算具体化方式：先在无答案参与的校准集上计算一种固定参考表示的每段序列化总字节量中位数 `B_ref`，取 `B={B_ref/16, B_ref/8, B_ref/4}` 并取整为记录在协议中的**固定字节数**；主预算是中间值。此后不随测试视频长度增长而上调预算。实际接口的索引、时间戳、检索键及持久化视觉证据均计入预算；若接口要求更高的最小容量，应在 discovery 前改定绝对字节数并留版本记录。

计算上限 `C`、输入分辨率、采样率及最长输出在校准阶段冻结；各基线均有机会在同一个上限内调优，不能只给新方法额外重编码或大模型调用。在既定帧输入与 reader 下至少测两类自然时间间隔：不超过 30 秒和不少于 5 分钟；将跨视频拼接结果单独标为合成干扰。数据不足以覆盖后一档时，结论仍是短时动态恢复，不写长期连续记忆。

若要进一步使用“Pareto 改善”措辞，须展示多个操作点的实际存储、观察端与查询端成本：在主区间，至少有一个新方法操作点在任务分数不低于对照的前提下减少一种资源，且不增加其他受限资源；或相同资源上限下分数更高。应给出测量波动及得分区间，不能把低于噪声的延迟差或峰值显存差叫作优势。G2 的准确率门槛本身不自动满足这个系统结论。

当前判断是：**可以按小模型主线开始，先做可审计的真实证据闭环；正式论文贡献应来自机制、算法和预算下的泛化证据，而不是“小模型 + FFT + Memory”这一组合。** 本文不预测录用概率，也不把未完成实验写成结果。
