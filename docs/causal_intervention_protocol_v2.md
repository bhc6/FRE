# V2：计算图负对照、中层干预与静态反事实

2026-11-01。本协议在新一轮干预QA之前写定；既有v1结果及8视频FFN描述性结果已知，全部仅作为开发信息。没有把已有40视频重新称为独立确认集。

## 推论与优先级

固定输入序列下，Qwen3-VL最后decoder层的视觉位置MLP输出发生在该层attention之后。其后仅有逐token残差、RMSNorm和词表投影。因此，只改过去视觉位置的该输出，对末端文本位置logits的Jacobian严格为零。先验证全36题的全词表logits精确不变；失败时停止并修hook，不能解释为新机制。该结构事实并非本项目首创理论。

中层13的视觉位置MLP输出能经后续attention影响答案，但“有因果路径”不等于“存在记忆瓶颈”，更不等于某种频带修改有益。

## 固定输入与条件

使用原8个开发视频、36个官方问题；每个视频读取已经核验的独立16帧manifest，按相邻帧形成8个视觉时间格。固定revision、BF16、512个视觉token/1024个总token上限、原多选提示及合法单token选项。所有条件在同一题上保持原RGB、时间戳、token位置、提示和选项完全一致；不重标原题。

条件固定为：baseline；末层27视觉FFN置零；末层27视觉FFN时间残差乘1.2；中层13 identity；中层13视觉FFN置零；中层13 FFN DC乘0.8、全部非DC乘0.8/1.2、高频乘0.8/1.2、低非DC乘1.2；中层13等高频扰动范数的全非DC增益；高频分量时间循环位移后的等范数方向对照；attention的非DC等范数对照；早层0 FFN高频乘1.2。

频率轴为同一空间位置、同一通道跨8个时间格；保留全部空间token，不先池化。高频定义为cycles/sample>0.25，低非DC为0<cycles/sample<=0.25；只改视觉位置。条件中的乘法作用于对应分量，其余分量不变。attention匹配的参考为同题baseline中层13 FFN高频分量L2范数；基于目标范数的系数不使用答案。记录cast到BF16后实际扰动范数，不能把请求范数相等冒充实际逐bit相等。

这类时间滤波在已观察完整前缀上操作，可能跨时间位置混合信息；不是逐帧在线因果更新器。所有条件作为开发机制筛查，并不按条件数量增加独立样本量。

## 读出与判定

逐题保存合法选项logits、预测、官方答案、gold-minus-best-other margin、全词表logit哈希及相对baseline最大误差；两种末层条件和identity必须全词表逐元素相同。保存原始记录后才做正确率与margin汇总。

主要候选在看新结果前指定为中层13高频乘1.2；比较baseline及等范数全非DC/循环位移/attention对照。其余为机制诊断，不因结果最好而自动替代主要方法。报告全部36题和原规则的temporal_state子集，使用视频聚合；小样本仅开发性描述，若加配对区间需明确不是独立确认。

进入新确认的最低开发门槛：目标时序题至少净纠正2题、至少涉及2个视频，全部问题不得净下降，并优于等范数时域对照。若只有大尺度破坏或单例变化，停止FFN频带增强主张，优先转向证据保留/空间局部性或读取瓶颈。条件可影响margin但不改变答案，不视为解决记忆失败。

## 静态反事实表示检查

另在相同时间槽位/提示下将16帧全部替换为同一首帧，或同一末帧，记录相同六分支。此时输入不包含视觉内容变化，非零时间谱仍可能来自位置、时间戳、因果上下文或数值误差。只分析表示，不沿用原QA答案评分，不将原减静态的差称为唯一的“真实动态”。

## 资源与冻结

所有真实推理使用同一ResourceGuard，allocator fraction=0.65、CPU两线程、一次一个GPU进程、单进程最多300秒。失败即停止，不自动提高限额。每次运行开始前保存协议/源码/数据hash，逐条刷新JSONL，原v1源码和结果不变。新未见确认数据只有在候选通过开发门槛并冻结后才用于一次主检验。
