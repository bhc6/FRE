## 数学分解与计算约定

令X[t,p,d]为同层同分支实际视觉token，T是8个时间格，P来自核验后的空间网格，D为通道。先沿时间去均值：

C[t,p,d] = X[t,p,d] - mean_t X[t,p,d]。

令M[t,d] = mean_p C[t,p,d]，R[t,p,d] = C[t,p,d] - M[t,d]。统一按坐标平均后：

mean_tpd C² = mean_td M² + mean_tpd R²。

因此，必须同时保存和报告全空间时间能量、空间均值时间能量、空间残差时间能量，以及数值闭合误差。沿时间的复FFT与空间均值交换；采用相同单边Parseval权重后，该恒等式逐频率成立。DC亦独立分解，不把DC称为背景噪声。

局部时间谱必须对每个真实空间token跨时间计算，不能用[T]空间二阶矩或最大RMS反推出patch频谱。空间索引只是处理器网格位置，不自动跟踪同一物体；跨帧运动与空间错位都会改变局部轨迹。

Q/K/V保留真实head维度，建议[T,P,H,D_head]。分别按每个head报告绝对能量，再做不重复KV头的聚合。Hq与Hkv可能不同；不得通过复制KV头伪造更多独立head。不同投影宽度及归一化改变能量尺度，不可把层间能量增长直接称为信息增长。

只有实际经过模型Q/K归一化和RoPE、按真实GQA映射、缩放和attention mask计算的点积，才能用于重建该层attention。若只保存投影后的pre-RoPE Q/K，只能称投影特征谱。只存visual keys会遗漏文本/timestamp等竞争keys，不能由局部softmax声称真实attention质量占比。

## 任务相关性最容易混淆的地方

通用提示Describe the visible events.没有指定具体QA。若所存视觉token位于问题文本之前，因果decoder的这些视觉状态不依赖后面的题目；同一视频的视觉谱不能不加说明地复制成多个不同问题的“任务特征”。应核验实际token顺序和mask，避免套用未经证实的假设。

若要分析题目如何读取历史视觉证据，需要另存与问题/选项有关的文本查询位置及其准确语义，例如产生首个答案logit的最后一个prefill位置。该位置不能与“已生成答案token”混为一谈，官方答案仅用于离线评分，不得进入prompt或探针特征。

即使拿到question-specific query/attention，attention大小也不等于任务证据充分性。必须结合独立核验的首/末态或最小证据位置，保留所有题目及否例。现有仅8视频，不适合训练高维分类器、反复挑频带后把同一开发集结果称为验证；本轮优先做固定统计量的描述性关联。

## 数据接口

每个capture metadata应包含：

- run/source/protocol/model/processor SHA与版本，condition、video_id、query_id或null。
- frame SHA、源PTS、展示PTS、hidden时间格、prompt及其SHA。
- 实际视觉token位置索引[T,P]、处理器grid、空间合并和索引顺序依据。
- 每数组的key、shape、dtype、层索引、分支名称、精确capture_stage。
- Q/K是否已经head norm及RoPE；query heads、KV heads、GQA映射与head_dim。
- 若有task query，保存其绝对token位置、token id及位于prefill/生成阶段何处。
- 保存的token范围和mask范围；是否包括所有文本keys；归一化/缩放约定。
- 无干预声明、有限值检查、残差或投影重算误差、资源与完成状态。

NPZ至少含timestamps_s[T]以及完整空间分支[T,P,D]；Q/K/V如可用使用明确head轴，并在metadata逐一描述。不能仅根据数组宽度猜head数、网格或capture stage。

V4实际归档的独立复核边界：完整visual Q/K/V只保存于3种中性提示条件，QA只保存末位置Q/K/V；没有保存所有文本位置K/V。全key的末位置参考attention行在采集时由实际SDPA入口Q/K、mask和scaling在CPU重建，且保存参考context与实际SDPA context。离线分析可独立复核保存行的归一化、mask及两个context间数值误差，但不能仅凭归档重新计算整个attention行或加权context。全词表logits相等和BF16残差恒等式则由离线程序直接从原始数组重算。

## 否决与后续门槛

1. 均值重算、Parseval/空间分解、残差恒等式或输入对齐失败，先停止解释并修复采集。
2. 如果真实与静态差异只来自未匹配的时间槽、prompt、像素或token数，本轮比较无效。
3. 如果谱变化在两种静态输入同样出现，只能保留“模型处理静态序列也产生时间变化”，不得命名为运动或记忆信号。
4. 如果没有question-specific证据接口，只交付表征诊断，不把它称为解决记忆错误。
5. 如果错误在完整输入和局部可读性检查中都不能恢复，先区分感知/计数/语言先验；不称遗忘。
6. 仅当一个固定机制在所有开发正反例上保持可解释、能定位与具体任务有关的证据损伤，才设计下一轮模型内部干预。当前不扫描层/频带寻找最好QA成绩。
7. 旧layer0selector失败保持独立记录。本轮内部谱结果既不能解释其失败，也不能修复其主比较。

复现任务审计：python -m spectral_memory.report_probe_tasks。新完整空间/QKV数据到达后，CPU分析器应验证接口并输出上述分解、real/static配对表和任务接口缺项，而不是自动拟合或挑选“最佳记忆频带”。
