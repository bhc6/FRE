# V2 前的独立 CPU 诊断：末层小修正为什么几乎不改变答案

日期：2026-11-01。范围：V1 的全部 206 条训练缓存、12 个最终控制器、2400 条训练日志及已完成的 V1 结果审计。没有执行 GPU、基座前向或新的训练。原冻结文件和结果没有修改。V1 train、validation、test 均已看；以下用于开发，不再把其中任何一组称作未见确认。

原始诊断位于 `outputs/v2_internal_diagnostics_v1/report.json`、`diagnostic_arrays.npz`、`step_diagnostics.jsonl`。脚本是同目录的 `diagnose_v1.py`。源文件、输入记录、缓存和 checkpoint 的 SHA 随报告保存。

## 1. 已能排除的解释

**10% context 限幅不是 V1 的主要阻塞点。** 训练真实 QA 中，即使允许每个 head 任意选择全部八个增益、放弃共享 MLP 的限制，原 basis 配合 `|g| <= 0.25` 能生成的最大修正仍远小于 10%。

令一个 head 的八个 basis 为矩阵 B，原生 context 范数为 n。由于范数是凸函数，增益盒上的最大值可在顶点取得；穷举全部 256 个符号顶点，得到

`max_{|g_r|<=0.25} ||sum_r g_r B_r|| / n = 0.25 max_{s in {-1,+1}^8} sqrt(s^T B B^T s) / n`。

这里是数值上完整枚举的表示上界，不是随机搜索；它还宽于实际共享 MLP 能实现的函数类。

| 142 条真实训练 QA × 16 heads 的描述统计 | 中位数 | p95 | 最大值 |
| --- | ---: | ---: | ---: |
| 视觉 attention 总质量 | 0.1694% | 1.8946% | 5.4601% |
| 原视觉贡献范数 / 原生总 context 范数 | 0.6364% | 4.7030% | 8.8619% |
| time 增益盒能产生的最大修正比例 | 0.1591% | 1.1758% | 2.2155% |
| spectral 增益盒能产生的最大修正比例 | 0.1853% | 1.3294% | 2.4463% |
| 保持视觉总质量、任意时间重分配的最大修正比例 | 0.5048% | 3.2704% | 7.7281% |

各 head 不是独立统计样本；本表仅描述已观察特征，不提供显著性或总体区间。最后一行把全部视觉 attention 质量集中到某一个时间格，保留格内相对 patch 权重，取八个 simplex 顶点的最大值。它是放松后的结构上界，不是已训练模型，也不是正确率上界。

实际 time 控制器使用了其增益盒最大可达范数的中位 83.6%–88.6%；spectral 为 70.8%–77.8%。time 的 25.2%–35.5% 增益坐标已达到至少 `0.95 × 0.25`；spectral 为 17.4%–20.4%。所有训练缓存上都没有触发 context cap。单纯延长相同参数化的训练，无法突破这个幅度上界。

**梯度没有断开。** 2400 步记录的梯度范数介于 `3.54e-6` 与 `2.19e-3`，均非零，0 步触发 norm=1 的裁剪。全部 142 条真实训练 QA 在每个 seed 的采样中均出现。Adam 的自适应缩放意味着小梯度本身不能推出参数没有学习；最终增益饱和和输入依赖已经表明参数发生了明显变化。

## 2. 条件特征的尺度不平衡

V1 用原生 context RMS 缩放带原 attention 质量的 basis，却把经过 head norm 的 query 直接连接进网络。实际第一层线性映射可以精确拆成 query 项、basis 项和 bias 项。basis 项范数 / query 项范数的中位数为：

- time：0.00159–0.00171。
- spectral：0.00234–0.00276。
- phaseblind：0.01423–0.01605。

把 basis 条件输入置零，time/spectral 的平均绝对 gain 变化只有约 0.00055–0.00151；把 query 置零则约 0.12–0.165。置零是分布外敏感性检查，不能作为唯一因果分解，但它与真实第一层项的尺度统计一致：当前网络主要由 query 驱动，basis 的条件信息相对很弱。

这不表示 query 只含文字，或末层小 visual mass 证明模型没有使用视觉。早期层已经可能把视觉内容写进文本表示。这里测到的只是最后 query 对视觉 KV 的直接 attention 质量与当前控制器的可达修正尺度。

## 3. 训练日志没有显示稳定的同样本目标改善

直接比较第 1 步与第 200 步的 CE 会混入 batch 难度变化。独立脚本按每条日志的六个真实 case ID，重算相同 batch 的原生 CE 和保存的 zero-replay CE，再从日志 CE 中相减。

以同 batch 的 zero-replay 为参照，首 20 步平均 CE 变化几乎为零；末 20 步各 run 的平均变化约为 `-0.00201` 到 `+0.00547`，方向并不一致。不能把不同 batch 下原始 loss 的上升或下降解释成收敛趋势。静态/真实 KL 与 delta 正则的平均加权量约 `5e-5`–`2.5e-4`；仅凭这些标量也不能断言正则梯度主导了训练。

保存的 206 条零干预 replay 中，batch8 与原生最大选项 logit 差达 0.25，并有 1 条预测改变；batch1 无预测改变。与之相比，V1 完整 test 中唯一被破坏题仅发生一个选项从 27.875 到 27.75 的变化，造成 A/B 平局。训练 proxy 的数值误差与一些真实干预效应处于同一量级，需要把两者分开报告，不能把 native→zero-replay 差异计作学习收益。

V1 test 的 12 个控制器均改变了全部 74 个真实问题的全词表 logits，但每个控制器仅有 3–13 条题的原三选项 logits 改变；真实题 gold-margin 变化的中位数均为零，0 条修复。time/spectral 三 seed 都从 identity 的 32/74 降至 31/74。三种 MLP 的增益确实随输入变化，仍没有任务收益。这些事实与低幅度、离散 BF16 读出以及尚未学到有效方向相容，但不能单凭本轮区分它们各自的因果份额。

## 4. 可证伪的原因假设

| 假设 | 已有证据 | 最小反证或区分实验 |
| --- | --- | --- |
| attention 质量乘在 basis 上造成幅度瓶颈 | gain 盒的精确上界；大量 gain 饱和但 cap 不触发 | 同 query/相同 MLP/相同 cap，把每个 basis 方向归一化后重新训练；若可达幅度和选项变化增大却仍不能改善训练目标，幅度不是充分解释 |
| basis 条件信息被 query 尺度压住 | 第一层项范数及置零敏感性 | conditioner 使用单位方向乘 sqrt(D)，同时报告 query/basis 两项尺度；与只改干预尺度的版本区分条件器与执行器作用 |
| 末层可控方向没有足够任务信息 | 目前没有直接可控性证据 | 只在已看训练样本，对每例自由的八个 routing/gain 做有标签的短优化诊断；它是上界/可控性实验，不是可泛化方法。若连该诊断都不能改善 CE，再增加共享网络容量缺少依据 |
| BF16/proxy 数值不匹配淹没局部更新 | 零 replay 可达 0.25 logit 差，真实选项变化稀疏 | 对同一批固定训练例同时记录 FP32 proxy、BF16 proxy 和完整 online 的 margin 变化；比较相同方向下的有限幅度响应，不能只看反向梯度非零 |

以上区分实验应先在已看训练/开发源做。旧 validation/test 可以用于明确标注的开发诊断；若选择 V2 的方法、幅度或层位置，最终确认需要另一个尚未用于这些选择的新 source 集合。

## 5. 最小内部路由候选

可以先移除频谱叙事，仅在最后 query 的视觉时间格上预测八个 logit 偏置。设 `m_t=sum_p a_tp`、`m=sum_t m_t`、`pi_t=m_t/m`、`mu_t=B_time_t/m_t`，令

`pi'_t = softmax(log(pi_t) + b_t)`，

`a'_tp = a_tp * pi'_t/pi_t`，

`delta = m * sum_t (pi'_t-pi_t) mu_t`。

原本零质量的格保持零；没有视觉质量时 delta 为零。它保留视觉总质量与格内 patch 的相对权重，并保留所有非视觉 attention 权重。仍使用实际 SDPA context 作 base，只加重分配产生的差值，以免 reference attention 的数值误差替换原输出。实现需在 `b=0` 时显式保证精确零差值，并核验普通 forward 的 identity。

如果 delta 超过既定每-head 半径，可用 `pi_effective=(1-alpha)pi+alpha pi'`，其中 `alpha=min(1,radius/||delta||)`；这是两个概率分布的凸组合，继续保留非负性和视觉总质量。它比原 `±25%` 逐格小增益允许更大的相对重分配，但不能逃开视觉总质量很小的限制；本缓存已给出其 simplex 上界。

若固定视觉质量的路由在训练可控性诊断中也失败，下一步应明确检验另一假设，例如允许一个有界 visual-versus-nonvisual logit 偏置，或在有更多直接视觉读出的较早层干预。前者改变视觉质量、只保持全部 attention 概率和为 1；不能误称视觉质量保持。后者改变的是干预位置及后续计算机会，不能用旧末层结果直接证明有效。

当前 root 指定的最小实现是**basis 方向尺度归一化**：保持原 basis 的方向与 query，把原 attention 幅度从 conditioner 和执行器的主尺度中移除，保留独立 context cap。这直接针对已测到的幅度瓶颈；它不是新的频谱记忆机制，正负结果都应按这个假设解释。规范化也可能放大原来很弱或噪声较大的方向，因此采用相对于 context 范数的 epsilon，并保留零方向。
