# 从频谱分析到可证伪的记忆研究：方案审计

日期：2026-11-01。本文是实验设计与数学检查，不包含真实 VLM 实验结论。文献事实及一手来源见 [逐篇矩阵](related_work_matrix.md) 的 R01–R18。

## 1. 推荐主问题及证据链

建议主问题：**在问题尚未出现、存储预算固定的在线观察阶段，如何保存未来任务所需的视觉状态变化与事件关系；频谱表示是否比同预算的时域表示更适合这一目标？**

按以下顺序建立证据：特征增量 → 受控干预 → 预算选择 → 真实长期读出。前一步成立并不自动证明下一步成立。当前 Probe 是前两步的研究工具，不是完成训练的长期多模态记忆系统。

与原方案相比，需先修正四个影响结论的前提：

- 完整 FFT 不会增加原时域序列的信息，只改变表示；应检验有限容量、有限数据或压缩预算下的归纳偏置。
- 幅度/功率谱本身无法识别时间方向；“放下/拿起”不能只用功率统计来区分。
- 标准冻结因果 decoder 的旧 token 表征不会因为后面追加 token 而被改写；必须测真正更新的记忆或未来读出。
- 写入时不能使用未来 query、答案、oracle 证据时间或未来瓶颈标签；检索阶段是否知道 query 要单列协议。

## 2. “独立信息”应如何表述

设时间序列为 (Z)，频域特征为 (F=g(Z))，未来任务收益为 (U)。因为 (F) 是 (Z) 的确定性函数，

\[
I(U;F\mid Z)=0.
\]

对完整的可逆 DFT，(Z\leftrightarrow\mathcal F(Z)) 是可逆重参数化，既不会自动增加信息，也不会凭空消除噪声。功率谱、频带统计或截断变换反而会丢掉部分信息。

可检验的主张应是：在预先固定的特征集合 (\phi_T(Z))、训练样本、预测器容量和计算预算下，添加 (\phi_F(Z)) 能否改善泛化。它说明频谱有用作表示或归纳偏置，不等于频域拥有时域中不存在的信息。R01、R02 已说明尺度频谱表征有先例，R03–R05 已覆盖频域缓存压缩。

最小对照包括 M1=语义，M2=语义+时域，M3=语义+频域，M4=三者联合。进一步用随机投影、等维度时域特征和强时间序列模型检查：提升是否仅来自额外维度、参数量或更复杂预测器。所有组使用相同训练集、调参机会、测试集和特征可见范围。

## 3. 功率谱、相位与方向：必须设置的失败测试

对实序列，反转序列的 DFT 与原序列的共轭仅相差相位因子，因此功率谱相同。时间循环平移同样保留功率谱。由此得到一个无需数据训练即可验证的反例：任何只依赖全局功率谱的分类器，都不能稳定区分任意序列与其反转的方向标签。

这不意味着 FFT 无法保留方向：**完整复数 Fourier 系数保留了时域序列的全部信息**。丢失方向的是弃相位、无序聚合和某些统计摘要。窗函数、去趋势和分段策略会改变具体不变性；反转测试须采用对称窗口和一致预处理，否则可能测到边界伪影。

建议至少加入：

| 对照 | 保留什么 | 改变什么 | 用途 |
| --- | --- | --- | --- |
| 原序列 vs 反转序列 | 全局功率与静态语义近似 | 时间方向、端点语义 | 检查功率特征能否被错误解释成动作方向 |
| 循环平移 | 全局功率、循环序关系 | 绝对事件位置 | 检查时间戳或窗口边界捷径 |
| 合法相位随机化 | 功率谱、实值约束 | 大量时间结构 | 检查模型是否需要相位；只作为诊断，不默认语义保真 |
| 频带删除 vs 等能量随机删除 | 扰动能量或维度数匹配 | 删除的位置 | 区分频带选择作用与一般信息损失 |
| STFT/局部统计 vs 时域分段池化 | 局部时间定位能力近似 | 表示方式 | 排除频域模型只是多拿到了局部顺序信息 |

相位随机化不能证明某频率在真实视频中具有因果作用：重构隐状态可能离开模型表征分布。需要范数/能量匹配、随机扰动、重构误差控制，再配合可实现的视频编辑或事件干预。没有匹配对照的频段删除，最多表明模型对该人工干预敏感。

## 4. 干扰测量必须有正确的状态对象

对固定权重、固定 prefix、固定位置编码和因果 mask 的 decoder，位置 (t) 只能依赖位置不晚于 (t) 的输入。追加未来 token (D) 不会改变已有位置 (t) 的计算依赖；标准 KV cache 的旧项也不会因 append 自动被重写。因此直接比较旧 token 的 (h_t) 与“追加干扰后的旧 (h_t)”常常只会得到机械上的一致。

例外包括显式 memory consolidation、缓存压缩/驱逐、位置重排、滑窗重计算、参数更新，以及非因果重新编码。这些操作都应记录，不能笼统归因为“上下文干扰”。即使旧状态不变，未来 query 的读出仍可能因注意力竞争、位置、检索竞争或证据缺失而下降。

应选择以下之一作为状态对象并明确命名：

1. **更新记忆**：(M_{t+1}=\mathrm{Write}(M_t,x_{t+1};B))，在相同预算 (B) 下比较目标事件进入前后及干扰后的可恢复性。
2. **检索与读出**：记忆内容保持相同，改变干扰候选，测 Recall@k、目标证据排名和答案正确率。
3. **重新编码表征**：在统一上下文下重新编码同一个事件。说明上下文可见性及位置是否改变，结果只解释为上下文依赖表征变化。

原材料的 (z_m(t)) 混合了“事件内部的视频时间”和“记忆进入后经历的时间”。建议使用 (Z_m(\tau)) 表示事件内动态，用 (M_n) 表示第 (n) 次更新后的记忆状态，用 (R(q,M_n)) 表示任务恢复能力。

## 5. 标签：边际收益不是静态重要性

固定背景记忆 (M)、候选事件 (m\notin M)、reader、query 和解码设置：

\[
U(m;q,M)=R(q,M\cup\{m\})-R(q,M).
\]

“加入”前后必须只有候选证据发生变化；若额外内容触发上下文截断、改变随机种子、使用不同 prompt 或更大的读出预算，标签已混入其他干预。预算已满时，加入需要替换某个事件，应另记 replacement utility，并保存被移除项，不能把它伪装成纯粹的 addition utility。

单个候选标签依赖背景 (M)。若 (m_1,m_2) 互补，可能各自单独无益、联合有益；若彼此重复，静态边际值相加会高估集合收益。因此静态预测分数的预算排序只是一项选择近似，不具备一般性的最优性或次模保证。最终必须用选出集合重新运行 reader，而不能把所选候选的单项真值求和作为最终任务准确率。

同时报告：收益预测误差、同一 query/背景记忆内的排序质量、固定预算下的实际任务分数。重复随机解码时使用配对种子，并报告均值和方差。若标签来自合成生成规则，结果只能证明实现与受控任务行为，不能称为真实 VLM 的反事实收益。

## 6. 写入与检索：两个不同实验

| 设置 | 写入时可见 | 预测对象 | 禁止的泄漏 |
| --- | --- | --- | --- |
| 事后查询的在线写入 | 当前和过去视频、已发生交互、过去记忆；训练所得查询先验 | 对未知未来问题分布的期望收益 | 未来 query、答案、测试问题类型、oracle 事件边界/证据位置 |
| 查询已知的检索或压缩 | 当前 query、冻结的背景记忆、截止该时点的候选 | (U(m;q,M)) | 测试答案、未来视觉事件、以 gold answer 产生的瓶颈向量 |

如果将显式瓶颈向量 (s_q) 放入 predictor，只能声称 query-conditioned retrieval，除非 (s_q) 来自写入时已经存在的任务状态。R15 InsightEmb 已明确关注当前决策瓶颈，不能把“比语义更关心是否推进任务”单独作为新颖性。

使用离线事件级标注可以做科学发现，但其事件边界若利用整段未来视频，必须称为 offline/oracle segmentation。在线写入版需要因果分段并允许事件关闭后的明确延迟；不能从离线结果直接声称零延迟在线能力。

## 7. 频谱估计中容易误判的细节

- **物理时间轴**：保存实际时间戳。视觉 temporal patch/merge 后的一个 token 时间格可能覆盖多帧，频率 Nyquist 上限由输出时间格间隔决定，不能沿用原始视频 FPS。
- **不规则采样**：不要把不均匀时间戳直接送入等间隔 FFT。统一重采样须记录插值及抗混叠策略；下采样不能仅抽点。无法满足条件时应拒绝数据或采用明确的不规则采样方法。
- **跨 clip 比较**：使用相同物理时长/窗长及 Hz 频段，限制在共同 Nyquist 范围；零填充只插值谱形，不增加真实频率分辨率。
- **直流和范数**：分离语义均值、动态总能量和归一化谱形。仅比较原始低频能量容易主要测到 DC、隐藏状态范数、场景不变或 clip 时长。
- **功率归一化**：记录 FFT 归一化、单侧谱倍增规则、窗能量与去均值/去趋势顺序；常量序列的动态谱熵不能出现 NaN。
- **时域等价性**：方差、差分能量和自相关都与功率谱有关。尤其循环差分能量按 (4\sin^2(\pi k/T)) 加权功率；只打败均值基线不够。
- **相干性**：单个窗的原始交叉周期图代入 (\lvert S_{xy}\rvert^2/(S_{xx}S_{yy})) 会退化为 1（非零处）。必须跨窗/重复样本平均并报告有效自由度，再讨论 coherence。可参考 [SciPy coherence 定义与 Welch 估计](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.coherence.html)。
- **基变换问题**：隐藏通道可被旋转；跨模型逐维相位不天然可比较。通道求和的总谱在正交基变换下不变，任意通道对的相干性并非如此。跨模型应比较任务表现或对齐后的统计，不能直接对通道编号作解释。
- **池化损失**：全局空间均值可能消掉局部物体移动。第一版只称 global pooled probe；物体或事件条件池化需要稳定追踪及独立评估。
- **稳定性指标**：原提案 (1-\lVert P-P'\rVert/(\lVert P\rVert+\epsilon)) 不对称且无下界，不能说它位于 ([0,1])。可报告对称距离及任务准确率，避免赋予未经验证的概率含义。

## 8. 数据划分与统计证据

同一原视频、主体、重叠窗口、反转/扰动版本、同一查询的候选集以及重复场景，不应跨训练/测试泄漏。先划分原始组，再生成增强、提取训练统计和构造反事实配对。若以主体为 group，应确保每个主体对应的所有派生视频在一个 split；跨用户和跨视频泛化不能由随机 event split 代替。

标准化、PCA、特征选择、超参数和频段边界，只在训练/验证数据决定。所有方法使用同一独立测试集，并对**原始视频或主体组**进行配对 bootstrap；不要对大量相关窗口做普通 IID bootstrap 得到虚假的狭窄区间。报告每组样本数、收益分布、随机种子、均值以及置信区间。

机制发现允许探索多个层、多个频带和多个窗长，但需要独立确认集或明确的多重比较处理。先寻找最佳层再在同一个测试集上报告显著性，会夸大证据。

## 9. 最小试验及停止条件

不建议把 100–300 小时原视频称为首轮 MVP。先以能覆盖多个主体/原始视频的少量数据建立可追溯的端到端闭环，再根据误差条和有效样本数扩展；具体规模应由可用数据和 pilot 方差决定。

1. **实现有效性**：合成低频/高频、常量、反转和等功率异相位例子；检查 Hz、无效时间戳拒绝、分组不泄漏、预算严格不超支。
2. **真实表征 pilot**：冻结一个骨干和固定 prompt，提取少量指定层。保存时间戳、模型/处理器版本、池化方法和原始视频关联。验证视觉 token 数与时间/空间网格一致。
3. **标签与读出 pilot**：使用具有状态/顺序/方向答案的事件及 paired reader calls 生成收益；固定背景和答案评分。失败案例区分检测失败、压缩丢失和检索竞争。
4. **表示增量检验**：运行 M1–M4、等维度对照、反转与时域强基线。将真实 query-conditioned 和 query-free 结果分开。
5. **有条件扩展**：仅在真实数据上的组级增量稳定后，加入在线记忆更新、长干扰、多模型及跨主体评估；再安排更昂贵的外部系统复现。

预注册一个最小有用改善量 (\delta\)，依据试点成本和方差决定，而不是事后按结果选阈值。若频谱相对强时域模型的配对组级置信区间无法支持有用改善，或收益在控制时间定位、维度和范数后消失，就保留“时序结构保留”的主问题，停止把 FFT 当作方法核心。

## 10. 适合论文的贡献边界

有潜力的贡献组合是：明确 query 可见性和真实更新机制的长期动态证据评估；预算可核算的时序结构保留方法；经过相位、时间、语义与容量控制的频谱表示证据。R11 已研究事件顺序，R15 已研究决策瓶颈，R03/R04 已研究频域缓存，因此这三类动机都需要更具体的新结果。

没有真实数据、强基线、因果对照和外部复现前，不预测录用概率，不以“必要成分”描述仅有相关性的频带。即使观察到稳定增益，结论也应限定为所用模型、数据分布、频谱定义、记忆接口和预算范围。
