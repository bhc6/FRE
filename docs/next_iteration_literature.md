# 下一版探索：覆盖半径约束下的轨迹重建选帧

日期：2026-11-01。状态：独立的理论与文献评估，不是已冻结v1协议的修订。本文没有读取确认集QA成绩，不提供本方案有效性结果，也不宣称新颖性。既有v1的主比较、预算、数据划分和判据保持其冻结定义；本方案若进入验证，须另立版本。

## 1. 要回答的具体问题

当前需要检验的不是“FFT能否发现短动作”，而是：**在不放宽初始k-center特征覆盖半径的条件下，改进分频带轨迹重建，是否比同约束下改进去均值时域重建更能保留有用的视觉证据？**

这把一个可能的取舍写清楚：低轨迹误差可能让少数异常状态失去代表帧；只优化最坏特征覆盖也未必保留事件演变。覆盖半径是可核算的几何限制，不能预先称作语义或短动作保障。分频带误差是另一个代理目标，不是QA效用的替代标签。

当前预算为4个原采样相邻frame-pairs，即8个图像输入槽位。时间隐状态行`g`对应原64个重采样槽位`[2g, 2g+1]`，不是把任意两个远隔帧重新拼成一个pair。相邻槽位仍可能映射到同一源帧，8个槽位不自动意味着8个不同的源图像。

## 2. 最小且可审计的数学定义

令完整候选轨迹为`X`，包含`T`行，锚点集合为`S`，预算`K=4`。先用与原k-center对照一致的表征、距离、固定首尾及tie-break得到`S0`。定义

\[
r(S)=\max_{t\in\{0,\ldots,T-1\}}\min_{s\in S}\lVert x_t-x_s\rVert_2,
\qquad \rho=r(S_0).
\]

可行集合为

\[
\mathcal F=\{S:|S|=K,\;\{0,T-1\}\subseteq S,\;r(S)\leq\rho\}.
\]

首轮探索应采用`rho=r(S0)`，避免新增松弛参数掩盖覆盖损失。如未来研究`(1+delta)rho`，`delta`须只在开发集选择并提前冻结，报告放宽后的实际覆盖半径，不得继续称“不劣于初始覆盖”。距离容差用于数值比较，须足够小且单独记录，不是未报告的松弛超参数。

令`A_S`表示按时间位置进行分段线性插值的算子，重建为`A_S X`，残差为

\[
R_S=(I-A_S)X.
\]

沿用现有保相位分频带损失。对非零轨迹能量，等价地使用单位正交全复DFT及对称频带写成

\[
L_{\mathrm{band}}(S)=\frac{1}{B}\sum_{b=1}^{B}
\frac{\lVert P_b F C R_S\rVert_F^2}
{E_b(X)+0.01 E(X)},
\]

其中`C`去掉时间均值，`P_b`选择非DC频带，`E_b(X)=||P_b F C X||²`。实际rFFT计算须使用正确的单边Parseval权重；常量轨迹等退化情形沿用显式边界处理。频带边界、归一化和数值容差不能根据QA结果临时调整。

必需的时域机制对照为

\[
L_{\mathrm{centered}}(S)=\lVert C R_S\rVert_F^2.
\]

它对应非DC频率的平坦平方失真；原始`temporal_reconstruction`包含残差DC项，不能单独用来证明分频带权重的贡献。已有`temporal_centered`可作为目标定义参照，但新约束下必须重新保持同初始化、同搜索过程。

### 2.1 一换一搜索

从`S0`开始，只考虑删除一个非端点锚点、加入一个尚未选中的候选位置。每一步在满足覆盖约束的候选中，按确定的规则选择严格降低目标的交换；没有改进即停止。记录接受的交换数、目标调用数、每步半径与目标，以及停止原因。

必须在两个目标间匹配初始集合、可行半径、候选集合、交换规则、tie-break及最大迭代次数。若需要耗时公平比较，还须报告真实CPU时间与目标计算成本；“迭代次数相同”本身不代表计算成本相同。

有限候选集合加上严格下降可以保证搜索终止，接受步的指定目标非增。它**不保证**全局最优、QA单调改善或短动作覆盖；也可能因为约束太紧而一次交换都无法接受。零交换率是应报告的结果，不能通过事后放宽约束隐藏。

### 2.2 先检查是否需要启发式搜索

当前`T=32, K=4`且固定首尾，内部只有两个锚点，全部组合仅

\[
\binom{30}{2}=435.
\]

因此可在CPU上枚举所有组合，对同一个覆盖约束分别求两个目标的精确最小值，作为优化审计。应报告可行组合数、局部搜索与精确最优的目标差、选点差异。若可行组合只有初始集合，两个方法必然一致；若大量组合目标并列，tie-break可能决定结果。

这里的“精确最优”仅针对这435个候选组合、既定表征与代理目标，不是最优视觉记忆。枚举也不能修复原候选池漏掉的动作。扩大`T`或`K`后再讨论可扩展搜索，避免在当前规模上把局部交换包装成主要算法贡献。

## 3. 覆盖半径究竟保证什么

直接可保证的是：每个**已经进入候选轨迹的hidden状态**到某个已存锚点的距离不超过`rho`，且最终半径不大于初始集合的半径。表征或距离发生变化后，这个保证不再自动成立。

一个有限的条件命题有助于理解边界：若动作对应候选子集`A`，且

\[
\min_{a\in A,\,b\notin A}\lVert x_a-x_b\rVert_2>\rho,
\]

那么任何满足半径约束的集合都必须至少选择一个`A`中的锚点。否则所有`A`中的点到已选集合的距离都会大于`rho`，与可行性矛盾。此命题要求动作已经被采样、动作与其他状态在该表征中充分分离；动作标注仅用于事后诊断，不得作为query-free selector输入。

通常不能假定上述条件成立，因而不能推出以下结论：

- 短动作必被保留：短暂变化可能被背景、相机或平均池化淹没，和非动作状态距离仍小于`rho`。
- 顺序与方向必被保留：覆盖只看状态集合；一次出现和多次重复、先开后关和先关后开可能具有相同或近似的几何覆盖。
- 已保留的动作可被回答：单个锚点或单个pair可能不足以展示动作轨迹，reader也可能无法利用已有视觉证据。
- 未采到的动作可被恢复：全局64帧候选若漏掉关键时段，后续选择无从补救。
- 物理动作频率被准确恢复：输入重采样没有明确的时间抗混叠低通，hidden频带不能直接等同真实运动频率。

不把普通无约束k-center的经典近似结论直接移植到强制首尾初始化、复合约束与频带目标。这里无需该定理即可核实“不超过初始半径”；若以后讨论近似比，必须指定相同可行集合内的最优问题并单独证明。

## 4. 频域目标的理论定位

对固定输入`X`，各频带分母固定，因此上述损失可写成

\[
L_{\mathrm{band}}(S)=\operatorname{tr}(R_S^\top Q_X R_S),
\]

\[
Q_X=\frac1B C F^*\left(\sum_b
\frac{P_b^*P_b}{E_b(X)+0.01E(X)}\right)FC.
\]

`Q_X`是数据依赖的半正定时间二次型。FFT提供计算与解释坐标；真正改变偏好的是各频带的相对失真权重。因此可检验的是特定权重在覆盖约束下的作用，不能把可逆坐标变换本身称为新信息来源。

Gram约化可精确保留这些时间线性算子的Frobenius损失、频带能量与L2覆盖距离，从而使CPU枚举更经济。它不自动保留逐通道幅值差：当前名为`spectral_power`的消融实质使用幅值差平方，若迁移到约化坐标须重新检查，不能冒充功率误差或认为正交旋转不影响它。

## 6. 下一版的最小比较与诊断

核心比较控制在三个方法：原`kcenter`、相同覆盖约束下的`temporal_centered`交换、相同约束下的保相位分频带交换。所有方法使用相同隐藏层、4个pair、首尾、候选池、实际图像大小和reader。先用枚举审计两种交换目标，再决定是否值得扩大实验。

机制诊断按明确问题增加，不能无限堆叠并事后选择赢的对照：

| 诊断 | 要区分的解释 |
| --- | --- |
| 去掉半径约束的同目标交换 | 收益或代价究竟来自覆盖限制还是谱权重。 |
| 同约束下的无相位幅值损失 | 是否依赖相位/时间位置；须保持原hidden坐标，准确标注幅值而非功率。 |
| 同表征的低通残差、相邻差分选择 | 是否只是偏好变化大或离群位置。 |
| 相同候选、相同预算的SGFS | 是否优于已存在的视觉多样性与时间分散目标；自适配帧对时须声明不是原作者设置复现。 |

至少记录四层证据：

1. **优化**：可行集合大小、交换数、精确最优差距、分频带及centered-time损失、覆盖半径。
2. **采样**：不同源帧数量、所选源PTS、时间间隔和首尾贡献。动作覆盖用`source_frame_timestamps_s`而非均匀目标网格`timestamps_s`计算。
3. **取证**：候选池是否见过动作、存储是否命中动作、是否有足够的动作前后状态；标注只用于评估。
4. **读出**：同reader的预先指定QA指标、按视频成对差及区间；区分“没有存到证据”和“有证据但reader答错”。

几何半径、重建损失和动作区间命中率都属于机制诊断；不能把任一项改善自动写成记忆改善。实际持久化NPZ字节、写入工作区、优化耗时、重新编码及读取成本须分别报告。

## 7. 与冻结实验隔离

本方案的选择、半径规则、候选池、预算、隐藏层和主指标不得依赖v1确认QA成绩。原8个开发视频可继续用于理解失败模式；任何受其启发的选择仍是开发，不产生确认性结论。

若v1确认集用于查看本方案、选松弛参数或挑指标，该数据对于新方案就已经进入开发过程。下一版应使用另行封存的确认视频，并按源视频/主体等约束防止衍生片段泄漏；不能把同一确认集的后验改善重新称为预注册检验。

继续条件应在新确认前写清：可行交换并非几乎总为空，代理改进不是单纯DC差异或端点效应，动作取证未被系统性损害，并且相对同约束`temporal_centered`仍有可独立检验的任务收益。若只改善谱损失、或仅在原8视频上选择性获益，应保留负结果并停止有效性主张。
