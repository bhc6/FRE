# V4：内部只读频谱probe的可否证研究

2026-11-01。此协议在新Q/K/V采集前写定。原8开发视频、36题的旧结果已知；所有本轮结果均为开发诊断，不称独立确认。主问题是频谱是否提供可解释、可复现的诊断增量；允许结论为没有。

## 固定实验

使用固定Qwen3-VL-2B revision、BF16、原16帧及时间戳、512视觉/1024总token上限。层固定为0、7、13、20、27，不按新结果选层。每视频3种中性提示条件：真实视频、首帧重复16次、末帧重复16次；后两者仅分析表征，不沿用原QA标签。另对该视频全部原官方题使用真实16帧采集末端文本读出位置。

每个条件先正常前向，再挂只读probe前向，要求全词表末位置logits逐元素一致，否则停止。本轮不改原权重、不回写激活、不训练adapter。最后一次卸载probe后再前向验证恢复。所有源码、配置、帧和输入token哈希保存。

## 观测量

真实记录6个残差/FFN分支；Q/K/V投影输出按真实head维度整理，另存Q/K归一化后和旋转后的张量。Q/K旋转后直接从原SDPA调用入口旁路复制，不使用重算结果冒充。记录完整[T,P,D]或[T,P,H,D_head]，不先空间平均；FP32存盘为BF16观测值的精确扩展。

只读分发wrapper在采集期间替换当前模型源码模块的attention分发对象，对原函数传入同一张量、mask和参数，finally恢复；不改attention实现或可见性。末文本位置attention行在CPU以FP64从实际Q/K、mask和scaling重建，另存实际SDPA上下文向量用于数值比较。参考概率不是SDPA内部导出的权重，也不是因果贡献。

中性条件持久化完整视觉轨迹；每道QA只持久化末位置状态和参考attention行，避免重复数GB视觉数据。不得声称QA存盘包含完整视觉轨迹。保留每类数组的形状、采集位置和布局。

## 主分析与否证

1. 先核对只读性、原始位置、模型/帧/源码哈希、残差恒等式、QKV布局及参考attention与SDPA上下文误差。
2. 同时报告全空间时间谱、空间均值谱、空间残差谱，验证逐频能量分解。固定patch不是跟踪同一物体，低能量不等于不含证据。
3. 同层比较真实与两个静态参照；分析Q/K旋转前后幅值及时间谱变化。静态非零谱不能直接叫运动；真实减静态也不唯一识别纯运动。
4. 对原36题报告基线行为和末位置读出，仅描述预定义题型及视频聚合。不能把一题的28层或多个head当独立样本，不能把attention权重当必要性/充分性。
5. CPU独立验证完整正交Fourier换基与同L2的线性/ridge probe等价。后续若研究频带/相位的低维先验，需与等容量时域、随机正交基、匹配非线性的控制比较；不宣称FFT创造信息。

旧8视频和3个主要时序视频不足以学习、选择并独立确认普遍机制。若仅见位置漂移或范数差，不启动以“修复记忆”为名的训练。需要任务特定的失败定位，再以因果抑制/恢复检验；频谱无增量时转向路由、局部证据可读性或其他已有分析方法。

## 资源

每进程一个视频，全部串行。ResourceGuard保持0.65 allocator、两CPU线程、300秒和既定温度/RAM停止线，不放宽重试。先video_1580工程检查，通过后才完成其余7视频。原始完整轨迹预计数GB，开跑需至少10GiB空闲磁盘；不持有跨条件GPU激活。此限制不能保证消除既往系统重启原因。
