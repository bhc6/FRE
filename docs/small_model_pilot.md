# 小模型真实试点：执行结果与研究决定

执行日期：2026-11-01。研究聚焦小型 VLM：**在固定存储和计算预算下，保留哪些时间动态结构，才能让小模型恢复过去的视觉事件？** 当前已完成真实接口与描述性诊断；没有完成频谱记忆算法或证明顶会级贡献。

## 已执行的模型与数据

使用本地缓存 `Qwen/Qwen3-VL-2B-Instruct`，revision `89644892e4d85e24eaac8bacfd4f463576704203`。硬件是 RTX 5070 Laptop，配置 BF16、SDPA、batch=1；独立 `.venv-cuda` 中的 PyTorch 为 `2.10.0+cu128`，torchvision 为 `0.25.0+cu128`，Transformers 为 `4.57.1`。未采购云算力，未改全局 CPU PyTorch。

Perception Test 官方 sample 共 8 段视频、36 道真实 MCQA、71 条动作标注，仅 1 道问题的官方 area 为 memory。主体身份未知；视频长度约 25.54–35.03 秒。这些数据已被用于开发，不能再作为独立确认集，也不是长程记忆基准。

每段视频按明确的全片均匀时间格准备 64 帧，保留原始帧索引、实际 PTS 和最近邻重采样误差。帧覆盖实际解码首尾；最大时间偏差约 0.014–0.017 秒。没有时间低通，因此后续频率解释仍需要采样率与混叠控制。

## 真实问答结果

每个问题运行 4 个条件，共 **144 次实际生成**。三个视觉条件都输入 16 帧：前半段均匀、后半段均匀、全片均匀。实际每次均为 **480 个视觉 Token**；总 Token 数随问题和时间戳变化，不能把它称为严格等计算预算。`uniform_full` 仅表示覆盖全片的 16 帧，不是完整视觉证据 oracle。

主评分事前固定为只接受单个大写选项字母，允许括号和句号；格式失败计错。正确答案仅在生成结束后评分，没有输入 reader。

| 条件 | 主评分正确数 | 问题平均准确率 | 原视频宏平均 | 格式失败 |
| --- | ---: | ---: | ---: | ---: |
| 无视频 `no_memory` | 13/36 | 36.1% | 35.6% | 0 |
| 前半段 `first_half` | 20/36 | 55.6% | 59.2% | 6 |
| 后半段 `last_half` | 21/36 | 58.3% | 61.5% | 4 |
| 全片均匀 `uniform_full` | 19/36 | 52.8% | 57.3% | 5 |

视频宏平均先在每个原视频内平均，再对 8 视频等权平均；不是跨主体结果。没有把同一问题的四个条件当四个独立样本，也没有在此小样本上宣称统计显著性。

原始输出见 `outputs/qwen3_qa36_pilot/report.md`、`records.jsonl`、`report.json`。另生成 108 个候选和 108 条成对效用：33 条 +1、63 条 0、12 条 −1，均相对同题的空记忆基线。每题空记忆只执行一次，成对日志引用该次真实 forward。日志含模型版本、帧哈希、提示、解码和实现源码哈希；这些效用只适用于当前 reader 与评分规则。

### 格式敏感性：事后诊断，保留主结果

15 个格式失败输出都以选项字母开头，后接选项文本，例如 `B. a tea`；部分文本因 8-token 上限而截断。事后采用“提取开头选项字母”的探索性规则，四组正确数变为 **13、26、25、24**，即 **36.1%、72.2%、69.4%、66.7%**。这说明格式遵循会影响主评分及方法排序，不能把所有计错都解释为视觉或记忆失败。

此规则是在看见失败后提出，没有覆盖原始 reward、paired utility 或主报告。它不能验证截断解释的正确性，也不能用于事后挑选最好的评价方法。可复算脚本与结果位于 `outputs/qwen3_qa36_pilot/analyze_format_sensitivity.py`、`format_sensitivity.json`。下一批独立数据应事前冻结约束解码或解析规则。

### 单道 memory 题无法支持记忆收益

预先关注的 `perception_test:video_1580:mc:1` 比较字母打乱前后的顺序，官方答案是 C/No。四个条件均输出 C，包括无视频组，所以三种视觉载荷的实测效用均为 0。不能由答对这道题推断模型保存了顺序，也不能把它包装成频谱方法成功案例。

## 真实隐状态与频谱诊断

从同一 8 视频每段 64 帧提取层 0、14、28，共 **24 个 `[32,2048]` 矩阵**。这是 8 视频的 3 个层，不是 24 个独立样本。提取提示固定为 `Describe the visible events.`，没有问题、选项或答案。层索引、DeepStack 和最终归一化与官方隐状态接口已独立核对。

实际隐状态 Nyquist 为 **0.4497–0.6167 Hz**；诊断固定频带 `(0,0.1,0.2,0.4)` Hz。24 个矩阵及 semantic/temporal/spectral/ordered/phase 五组特征全部有限，每组维度分别为 **2052 / 16384 / 63488 / 32768 / 36864**。

实测最大相对误差：反转后的 boxcar 功率谱 `3.79e-16`，PSD Parseval `1.84e-15`，保序/复频谱能量 `5.78e-16`，复频谱逆变换 `1.98e-16`。这些是数值正确性证据，也再次说明仅看全局功率无法识别反转方向。

Hann 非 DC 通道能量池化后，低频 `(0,0.1]` 份额在层 0/14/28 的视频等权均值为 **0.4664 / 0.5583 / 0.4634**。大于 0.4 Hz 的剩余能量单列，没有重新归一化掩盖尾部。该层差异不等于记忆重要性，更不能称为长期记忆机制。

三层同时提取的模型前向总耗时约 9.46 秒，峰值 allocated 4.827 GiB；不包括模型加载及视频准备。完整结果、每视频指标和数值定义见 `outputs/qwen3_hidden_pilot/diagnostics.md`、`diagnostics.json`、`manifest.layer_*.jsonl`。

没有把 64 帧全片的隐状态强行贴上 16 帧候选的效用：二者载荷不同。当前没有训练效用预测器、做独立划分或运行频谱指导的选择方法。

## 研究决定

**继续小模型主线，但不能据此认定频谱路线成立。** 本机已能完成真实读出与多层提取，新增视觉证据可以改变部分答案；然而全片均匀条件未超过半片条件，唯一 memory 题又可在无视频下答对，当前不足以分辨感知、检索、时序压缩或长程遗忘。

下一阶段需在新的公开视频上建立有证据定位、无视频捷径更少的顺序/状态任务，冻结解析协议，比较强时域、保序、相位与频谱选择，并实际评估选中集合。长期主张需要真实长视频与干扰；小模型特有主张需要第二模型与同家族尺度控制。完整投稿定位、直接竞争和新数据 Go/No-Go 门槛见 [小模型研究定位](small_model_research.md)。
