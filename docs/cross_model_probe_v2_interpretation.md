## 不支持的笼统故障解释

Qwen真实视频6/8正确，Smol为3/8。Qwen换成重复首/末帧后分别3/8、4/8改变选项，选项分布TV均值0.2001、0.2089；Smol均为1/8改变选项，TV均值0.0827、0.0591。Smol在这批题上对时变输入的输出响应较弱，是一个待复核的描述。

但Smol最后层的visual attention mass与visual/native context范数比分别为0.03583和0.07838，均高于Qwen的0.00408和0.01216。因此结果不支持“最后层直接视觉attention少就是失败”或“增加该mass就会提升推理”。模型、输入预算和数据处理不同，不能据此建立单变量因果关系。

两模型在早、中、晚层的real减平均static的V非DC占比均在8/8源上为正；Qwen区间均值依次0.2775、0.3211、0.3827，Smol依次0.1694、0.1852、0.2474。没有观察到“V的时变内容在深层整体消失”。FFN/attention范数比在最终层分别约5.00和8.42，但分支范数大小不等同于压制、遗忘或因果重要性。

## 观察到的频谱混淆

Qwen的attention-weighted visual context呈相反现象：中层、晚层与最终层的real减平均static的非DC占比分别为−0.1573、−0.1843和−0.1045，每个区间均为8/8源负值。静态输入可以比真实视频产生更强的加权context非DC占比，而原始V非DC占比仍明显较小。

令一个query head在时间t的视觉context为 u_t = sum_p a_tp V_tp，并写成 u_t = alpha_t z_t，其中 alpha_t = sum_p a_tp、z_t为条件视觉context。即使z_t恒定，时间attention质量alpha_t的变化也会给u_t引入非DC。因此加权context频谱混合了内容变化和attention包络。当前观测符合这一混淆，但仅凭已存频率能量不能分解两者的各自贡献：没有归档原始逐时刻u_t，不能事后重建条件归一化z_t。

这是比“mass小”更明确、可证伪的问题：把加权context的高频直接当成运动或事件信号，会对静态输入产生假阳性。它仍然是诊断特征的混淆，尚未证明它导致某个任务答案错误，也没有证明移除混淆能提升准确率。

## 下一步机制检验

1. 在相同旧开发源与固定层上同时计算原始V、u_t及z_t的时间谱，明确alpha_t接近零时的处理。加入固定图像、相同帧集合的置换与倒序。若z_t仍有静态频率，检查位置与因果上下文，而不将其继续称为运动。
2. 总非DC能量就是时间去均值方差。任何频率方法都需要与直接时域去均值/方差、相同参数数目的时域控制比较；仅改善real/static判别不能证明频谱独特性。
3. 针对Smol的重复动作计数、物体出现计数、顺序题，检查错误是否来自输入采样、内容识别或最终使用。video_6532两模型都选“2”而金标“6”，均匀16帧可能未保留充分的重复周期，必须先区分采样不可辨识与内部读出问题。
4. 若要定位内部使用，固定视觉token布局，只在预先选定层做真实/静态V的局部替换或去时间均值干预，保留Q/K与文本路径，并测完整输出变化。只有干预结果和任务相关证据共同支持时，才设计可部署控制器。
5. 中层delimiter缩放可作为现成可部署基线；需要与后续残差更新damping的等价控制比较。它的收益不能自动解释为更多直接视觉attention或频谱记忆修复。

所有选择均仍处于已看开发数据。不得把这8个异质首题当成普遍跨模型机制的确认集；未见确认源不参与本报告，也不能在控制器选择后反复试验。

## delimiter缩放数学审查

在固定token集合S、正且固定的lambda、精确尺度不变的逐token pre-norm、没有额外残差注入的条件下，某层后将S的残差乘lambda，等价于不缩放残差而将所有后续attention与FFN在S上的更新乘1/lambda。每次残差加法后的两路状态仍分别满足lambda倍或完全相等，归纳证明成立。

Projection bias本身不会破坏该等价：归一化输入相同时，带bias的投影输出仍相同。真实RMSNorm的epsilon与BF16需要测量近似误差，不能从CPU阈值passed推成定理意义上的精确等价。lambda=2在二进制浮点正常范围具有特别有利的缩放性质，不能直接推广任意实数lambda。Qwen额外DeepStack注入位于最早若干层，中层之后没有该注入，当前选择符合该限制。
