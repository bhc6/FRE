# 编码器频谱：测量对象、池化与信息解释

2026-11-01。配套实现为 `spectral_memory/vision_encoder_probe_v2.py`，冻结采样协议为 `docs/vision_encoder_probe_protocol_v2.md`。以下恒等式解释测量，不构成新的算法或准确率结果。

## 1. 先固定张量与轴

把实际视觉网格恢复为实数张量 `X[T,H,W,D]`，令 `P=H*W`。单张图具有空间轴 H/W；视频还具有采样时间轴 T。编码器的 temporal patch、merger 和 pixel shuffle 决定实际网格，不能从输入帧数或扁平 token 数直接猜测。

- 时间谱：每个空间位置、每个通道分别沿 T 变换，最后汇总功率。
- 空间谱：每个时间组、每个通道分别沿 H/W 做二维变换，最后汇总功率。
- D 是特征坐标，没有预先建立的频率邻接意义。本实验不沿 D 做 FFT。

Qwen 的十六帧输入在这里对应八个相邻帧 tubelet。Smol 对应十六个独立帧编码。两者的频率 bin、空间网格和归一化不同，不能按同一个数组下标比较物理频率。

## 2. attention 加权信号并不是原始内容信号

对固定 query/head，定义视觉时间组的 attention 质量和条件内容：

`alpha_t = sum_p a_tp`

`mu_t = sum_p a_tp V_tp / alpha_t`，仅在 `alpha_t > 0` 时定义。

缓存的加权读出轨迹是 `B_t = alpha_t mu_t`。即使 `mu_t = u` 为常量，也有 `B_t = alpha_t u`；只要 alpha 随时间位置变化，B 就有非 DC 能量。单位化 DFT 下有：

`F(B)_k = (1/sqrt(T)) * sum_j F(alpha)_j F(mu)_(k-j mod T)`。

因此 B 的谱同时包含时间权重包络和内容，其频率成分不能直接命名为事件或运动。除以 alpha 只移除了时间组质量，mu 仍含格内空间 attention、上下文和位置因素；它也不是未加权 V。小质量下还必须记录阈值和数值稳定性。

本地旧训练集的实际反转结果与零质量规则见 `docs/readout_spectrum_confounds_v2.md`。不要把这一测量修正改写为已经修复原模型的错误。

## 3. 总非 DC 能量恰好是时间方差能量

使用正交归一的完整 DFT，令 `Z_tp = X_tp - mean_t(X_tp)`，则 Parseval 恒等式给出：

`E_temporal_AC = sum_(k != 0,p,d) |F_T(X)_(k,p,d)|^2 = sum_(t,p,d) Z_(t,p,d)^2`。

所以一个总非 DC 占比本身没有超出时域去均值平方和的额外信息。频率分配、相位、不同位置或通道之间的关系才可能提供更细的描述；是否对任务有用还需验证。单边 rFFT 要对内部频点加倍，DC 和偶数长度的 Nyquist 不加倍。

## 4. 先空间平均可以消去时间变化

定义 `Y_t = mean_p X_tp`。比较完整逐位置的时间变化和均值轨迹时，应使用：

`rho = P * sum_t ||Y_t - mean_t Y_t||^2 / sum_(t,p) ||Z_tp||^2`。

分母为零时 rho 未定义，不能填成零。分母为正时 `0 <= rho <= 1`。理由是把每个时间点的 P 个位置投影到空间常量子空间，所得张量为 `mean_p Z_tp` 在 P 个位置上的重复；正交投影不增加范数。rho 恰好是时间变化能量在这个空间常量子空间中的比例。

反例：两个位置分别为 `X_t1 = u + v_t`、`X_t2 = u - v_t`，且 `mean_t v_t = 0`。完整信号的变化能量为 `2 sum_t ||v_t||^2`，但空间均值恒为 u，因此 rho 为零。不能根据均值轨迹没有 AC 推出编码器没有动态表示。

这个比例描述分析者所做的空间平均。当前原生模型仍接收所有保存的视觉 token；未证明模型在前向中实施了这个池化，更未证明相同比例的任务信息已经丢失。

## 5. 空间 AC 减少不等于压缩损失

无损 space-to-depth 只是把局部空间索引移入通道：

`X[T,H,W,D] -> G[T,H/s,W/s,s*s*D]`。

它是元素置换，总能量与沿 T 的总 AC 都严格不变。然而空间常量子空间发生变化，沿粗 H/W 计算的空间 AC 可以改变。将一个 `2x2` 棋盘格完整打包到 `1x1x4` 通道后，空间 AC 为零，却可以逐元素恢复原图。

真实 connector 随后还有线性投影、非线性或归一化，无法仅凭前后功率判断信息可逆性。前后空间 stride 不同，也不能把各自 Nyquist 的同一百分比当作同一 cycles/image 频段。本实验保留完整网格、频率坐标及逐元素能量，阶段间 AC 比例仅作描述。

## 6. 灰图是必要控制，但不是可直接相减的纯位置成分

均匀灰图的像素空间 AC 为零，编码器输出却可能因位置编码、边界与训练后的计算具有空间 AC。这说明 hidden 空间 AC 不全是图像纹理。真实内容与位置通过非线性混合，通常不存在 `encoder(image) = content(image) + encoder(gray)` 的分解；直接减去灰图表示不能自动解释为去除位置噪声。

相同输入尺寸和相同预处理的灰图会重复产生同一表示，重复源数量不构成新的独立灰图样本。重复帧若在后续因果 decoder 出现时间 AC，还需再区分位置和上下文计算。

## 7. 从测量进入方法研究的最低条件

先在明确轴和对照下定位稳定的表征差异，再检验差异是否对应原生模型的任务错误。干预须保持共同输入、视觉预算、选项映射和读出精度，并提供相同预算的时域控制。对总 AC 的统一增强等价于调整时间去均值残差，不能仅因用 FFT 实现就主张频谱特有优势。

严格的时间反转与谱相位限制、现有 phase intervention 工作及最小反事实设计见 `docs/encoder_spectrum_identifiability_v2.md`。本轮编码器探针保持所有原生 logits 不变，只建立后续因果实验的测量基础。
