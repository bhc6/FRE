# V3研究重定位：模型内部时序证据的传播、诊断与干预

2026-11-01。根据用户对“记忆”的明确界定更新主线。本文件是后续研究设计，不是已完成训练、成功实验或已冻结的独立确认协议。原v1选择器和v2记录继续保留；停止把外部选帧优化作为当前创新核心。

用户进一步明确：“在FFN/attention内部挂probe，读取输入相关的隐状态、残差或Q/K/V”。当前首要方法是内部激活的只读探测与频谱诊断，不是预先给网络增加频谱adapter，也不是直接对权重矩阵做时间FFT。后文低秩支路仅为可选干预，不代表已经确定的最终方法。

probe在指定计算节点复制状态h_l[t,p,d]，沿时间计算S_l[k,p,d]=DFT_t(h_l)。观察阶段不回写激活、不更新原模型参数、不改变答案计算路径。若进一步训练频谱模式读出器，它仍是独立诊断器：冻结主干、隔离训练与测试视频、不把读出器的输出送回主干；只有另设干预实验才修改模型计算。probe的诊断能力与干预的问答收益分别验证。

现有probe_ffn.py属于这类只读hook，已采集0/13/27层六个残差/attention输出/FFN分支。它尚未单独采集Q/K/V，存盘主要为空间均值及矩统计，因此不能称为已完成全层、全空间、全QKV频谱定位。

## 1. 研究对象与可检验主张

研究对象是已输入模型的事件证据在视觉编码器、语言残差流、attention的K/V与文本读出位置之间的传递。称作“内部时序证据保持与读出”比笼统的“记忆涌现”准确。单次forward的激活本身不构成跨请求持久记忆；若讨论长期保持，必须明确历史保存在KV、递归状态还是外部上下文中。

设外部harness为M，预算为B，输入视频X、问题Q，经harness得到C=M_B(X)。基线输出为f_W(C,Q)，内部方法为f_{W,theta}(C,Q)。每个配对条件保持C的字节、时间戳、token位置、问题及答案选项相同，改变的只有模型内部的指定计算。

目标主张：在预定义、保留足够证据的任务族中，通过内部probe频谱诊断定位小模型可干预的时序证据传递失败；再依据定位选择原参数调整、激活/路由干预或必要的小模块，在未见视频及未参与调参的harness上，以相同输入/存储预算检验问答表现。不能在定位之前把新增adapter当成既定方法。

“所有harness必然改善”不是可保证命题。外部方法若删除决定答案的信息，内部模块不能保证恢复该视频的事实。固定训练后参数且不使用测试答案时，条件数据处理不等式给出I(Y;prediction|Q,W,theta) <= I(Y;C|Q,W,theta)。训练先验可以提高猜测，但不能把猜中当作恢复已删除的个例证据。也存在已经100%正确、空输入、纯文本摘要等边界。因此确认目标是有限预声明harness集合的迁移收益、最差组变化和不伤害范围。

## 2. 内部隐状态如何取

遵循本地源码已核对的实际计算图，详见structural_mathematics.md。视觉状态保留H_l[t,p,d]，时间t是视觉两帧patch对应的物理时间格，p为空间位置，d为特征维度；不沿通道编号或混合文本/视频的token总序号直接解释为运动频率。

至少区分以下取点：decoder入口残差；attention的输入及输出增量；FFN前残差；FFN归一化输入；FFN输出增量；FFN后残差。早三层另记录DeepStack注入边界。诊断attention时区分Q/K旋转前后与V，并跟踪问题/答案位置读取视觉证据的路径。output_hidden_states不能代替这些支路取点。

空间平均只作低成本汇总。局部动作可能在平均时抵消；主诊断应在同空间位置沿时间计算后聚合，并承认固定patch不等于跟踪同一运动物体。已有16帧探针存盘主要为空间均值，不能从它重建完整空间频谱。v2干预曾在完整[T,P,D]张量上操作，但这不等于已把完整张量保存下来。

跨harness通常产生不均匀时间间隔。FFT按采样序号的频率单位为cycles/sample，不能比较为相同的Hz。主定位先使用统一时间网格；后续必须预声明时间戳感知基底、采样间隔输入或仅限均匀采样的适用范围，不能静默插值后宣称恢复未观察信息。短至8个时间格只支持很粗的频率分辨率。

## 3. 从频谱到任务因果作用

对单位DFT F，令Hhat=FH，频率能量E_l(k)=sum_{p,d}|Hhat_l[k,p,d]|^2。单位Parseval保证总能量等于时域能量，但不保证其中包含正确答案的信息。

对实数序列逆序会保留功率谱却改变相位；先后顺序相反的视频可以具有相同的谱能量。因此“学出谱模式”需要考虑相位、跨层或跨支路交叉谱、与事件标签相关的子空间，不能只学习高频/低频能量比例。固定空间位置仍会受摄像机运动与目标移位影响。

若答案margin为m，目标内部状态为H，小干预为delta H，则

    delta m = <grad_H m, delta H> + O(||delta H||^2)
            = Re <F grad_H m, F delta H> + O(||delta H||^2).

这是全频率、单位DFT、实数原序列下的局部表达；非光滑margin在最大错误选项切换处需分段讨论，也可用平滑交叉熵代替。功率大只控制范数，不决定上式符号。有限差分、activation patching与真实QA变化用于核查局部近似，而非从能量推断机制。

层间某个线性probe变差，只表明该probe的可读性下降，不证明全部信息被抹除。先固定probe容量并用按视频划分的独立集，再检查attention路由和干预救援。如果视觉状态仍可读、问题位置不可读，应优先研究路由/读取，而不是继续扩大FFN频带。如果视觉编码器入口已不可读，向后调整语言FFN缺乏定位依据。

最后层过去视觉位置的FFN输出对末端文本答案没有路径，在既定边界下其答案梯度也为零。这是实现负对照，不是新颖性主张。中间层FFN有路径但未证明是瓶颈。

## 4. 可学习内部方法：候选而非结果

先定位，再决定干预位置；不把中层13或高频固定成科学结论。优先比较低参数残差模块，冻结主干并限制扰动范数。一个保持时间因果性的候选为：

    Z[t,p] = W_in H_l[t,p]
    delta H_l[t,p] = W_out sum_{lag=0}^{K-1} diag(c_lag) Z[t-lag,p]
    H'_l = H_l + delta H_l.

过去越界项为零。W_out零初始化，W_in采用非零初始化，避免整个模块同时为零导致无法学习。时序频率响应为G(omega)=sum_lag diag(c_lag) exp(-i omega lag)。该公式连接可学习前向变换与频谱诊断，但有限FIR与其频域表达是同一个线性操作；“用了FFT”不能单独成为创新。FFT实现线性卷积须足够零填充，不得默认为循环边界。

若移位算子使用零填充，其谱范数至多1，因此||delta H||_F <= ||W_out||_2 ||W_in||_2 sum_lag ||diag(c_lag)||_2 ||H||_F。这个上界有助于控制增益，不是准确率保证，也不证明较小扰动必然安全。

只有机制证据表明特定频率/相位响应相关时，才加入诊断指导的参数约束或目标。必须与同参数时域FIR、普通通道adapter、随机频带/相位及无模块训练对照比较。用于训练的证据监督或教师结果必须来自训练划分，部署不能读取正确答案或额外视频。

对不均匀采样，以上离散lag定义只能解释为采样槽位；要跨采样策略使用，应另评估时间间隔条件化的核并记录其额外参数。纯文本摘要harness缺少视觉时序网格，当前模块不适用；需要另设文本路径实验，不能将视觉harness结论外推。

整段FFT后修改每个过去视觉token会引入时间上的未来依赖；即便答案已能看到整段，也改变了原始decoder的内部可见性。这样的离线块实验可作上界对照，必须单独报告，不得称原生因果或在线方法。在线版本只能使用当前及过去可见状态，并需要prefill与逐步cache一致性检查。单个支路因果不代表整个视觉前端原生流式；视觉attention、两帧patch的等待和分块边界还需独立核查。后置问题若控制过去token模块，也须明示重新prefill，不能隐瞒额外计算。

## 5. 预算与共享方法

每种harness内首先逐字节固定输入payload，视觉token数、分辨率、提示、precision、生成设置一致；随后比较同一模型有无模块。横跨harness的同预算要分别报告RGB或token payload与KV字节，不能把不同介质的“8帧”或“8K上下文”称为严格相等存储。

模块的参数、缓存、峰值显存、耗时与FLOPs单列。上例D=2048、rank=16、K=5时共有2*2048*16+5*16=65,616参数，无偏置。若在线缓存四步、60空间位置、BF16，则额外缓冲为4*60*16*2=7,680 bytes/干预层；这些是架构计算而非已测部署开销。严格总存储约束应将其计入并在两组分配相同上限。

共享theta在训练集上一次学习，不能每个harness看测试答案后另行调参。至少留出一种harness完全不参与训练/验证；分别报告各方法差值、视频级区间、宏平均、最差组和出现损害的题型。若要求“所有已测试方法改善”，需预声明所有组均达标的统计判定并处理多重比较；平均提高不能替代该结论。

## 6. 证据链与停止规则

1. 明确失败：使用能核对事件顺序/状态的标注和保持题意的反事实。证明同一输入确实包含回答所需证据；全帧模型答错不能直接标成内部遗忘，单次probe可读也不能证明模型原来会读。
2. 分层定位：在同内容/位置控制下记录视觉、FFN与问题/答案路径。报告绝对能量、DC、相位/交叉谱及受控probe；静态重复帧只是参照，不是纯位置项或纯运动分解。
3. 因果检验：对有路径的层进行有针对性的抑制、救援与交换；包含同范数、同参数、非频谱与结构断路对照。分别验证必要性与救援，避免把一般扰动敏感性称特异机制。
4. 学习干预：只在训练划分拟合小模块，在开发集选架构/层，先完成单批前向与反向资源测量。8个旧开发视频足以调试，不足以训练并证明普适频谱规律。
5. 独立确认：冻结代码/权重/超参/主指标后，使用排除已看过8+40视频及重复内容的新视频。验证同一theta跨harness、跨时长/位置/干扰与至少一个额外小模型；资源无法覆盖的部分明确保留缺口。若主张瓶颈“小模型特有”，还需同任务的大模型对照；仅在小模型上观察到现象不支持特有性。

无明确内部失败就停止“解决内部瓶颈”的措辞；有诊断无救援则仅报告机制候选；收益只在一种harness出现就收窄适用范围；频谱约束不胜等参数时域方法则撤回频谱必要性主张。保留负结果，不在独立确认集反复搜索新方法。
